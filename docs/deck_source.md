# Источник презентации

`src/build_deck.mjs` генерирует 12 слайдов из `results/deck-data.json` и научного рисунка сети.
Данные графиков сохраняются как редактируемые диаграммы со встроенными книгами в PPTX.
Числа в диаграммах округлены до шести десятичных знаков для совместимости с Excel.

Генератор использует `@oai/artifact-tool` и инструменты проверки из Codex primary runtime.
Это зависимость только создания презентации. Научный расчёт и отчёт воспроизводятся обычным Python3.12.

Для пересборки графиков в ином презентационном инструменте используйте:
`results/profiles.csv`, `metrics.csv`, `temporal_stability.csv`, `external_validation.json`,
`interpretation.json` и `confidence_latest.csv`. Финальные PDF и PPTX уже включены.

## Дополнительная проверка интерактивной страницы

```bash
npm install
npx playwright install chromium
npm run check:browser
```

Проверяется переключение месяца, выбор территории, ошибка неизвестного ID, отсутствие браузерных ошибок и горизонтального переполнения на мобильной ширине. Для расчёта кластеров npm и браузер не нужны.
