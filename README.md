# Экономический отпечаток муниципалитетов

Решение для конкурса СберИндекса 2026, направление **«Кластеризация»**.

Динамические атрибутированные сети потребительских профилей 2 016 муниципальных территорий за январь 2023 — декабрь 2024. Исследование использует реальные открытые данные Лаборатории СберИндекс. Исходные данные включены с лицензией и SHA256, все числа в материалах получены при запуске кода.

## Посмотреть результаты

- `docs/presentation.pdf` — 12 слайдов для жюри.
- `docs/methodology_ru.pdf` — русский методологический отчёт.
- `docs/interactive.html` — автономная интерактивная визуализация, открыть в современном браузере на компьютере.
- `results/summary.json`, `results/metrics.csv` — численные результаты.

Интерактивная страница работает без сети: месяцы, выбор territory_id, профили территории и группы, ближайшие экономические соседи, траектории исходных долей, Sankey и метрики. Если мобильный файловый просмотрщик не выполняет JavaScript, откройте HTML в браузере на компьютере. Для конкурса HTML можно опубликовать через GitHub Pages, см. `SUBMISSION.md`.

## Что найдено

- Полная панель: 2 016 из 2 190 территориальных идентификаторов, 24 месяца. 174 территории исключены из-за неполных рядов, без заполнения пропусков.
- Семь потребительских групп в декабре 2024.
- Средняя по МО доля маркетплейсов выросла с 11,7% в 2023 до 15,9% в 2024. Рост положителен в 99,6% пар «территория–месяц» при сравнении одинаковых месяцев год к году. Средние не взвешены по населению.
- Leiden лучше по сетевой изоляции, K-means по разделению признаков. Единственного победителя по всем метрикам нет.
- 1 239 МО имеют поддержку метки ≥80% в 12 запусках с разными seed; 777 остаются пограничными.

Это типология структуры **безналичного потребления жителей**, а не доказанная отраслевая типология, доход или рейтинг качества жизни. Каталог названий и карта границ не подключены; используются идентификаторы исходного датасета. Подробные ограничения в отчёте.

## Воспроизведение

Python **3.12**. Зафиксированные версии в `requirements.txt`. Исходные parquet уже лежат в `data/raw`.

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=1
python src/pipeline.py --config config.yaml
python src/visuals.py
python src/report.py
python -m unittest discover -s tests -v
```

### Windows PowerShell

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:OPENBLAS_NUM_THREADS="1"
$env:OMP_NUM_THREADS="1"
python src/pipeline.py --config config.yaml
python src/visuals.py
python src/report.py
python -m unittest discover -s tests -v
```

Для генерации отчёта нужен шрифт с кириллицей. По умолчанию используется DejaVu Sans. На Windows передайте переменные `REPORT_FONT` и `REPORT_FONT_BOLD` с путями к установленным `.ttf`, например Arial. Сам расчёт и HTML не зависят от этих шрифтов. Для пересборки PPTX/PDF презентации смотрите `docs/deck_source.md`; численные результаты воспроизводятся независимо от презентационного инструмента.

Полный численный расчёт в авторском окружении занимает около 36 секунд, время зависит от устройства. Рекомендуется не менее 4 ГБ доступной памяти. Генерация материалов занимает дополнительное время. Порты, API-ключи, базы данных и сервер для расчёта не нужны. Локальный просмотр: `python -m http.server 8000 --directory docs`, открыть `http://localhost:8000/interactive.html`, остановка `Ctrl+C`.

## Метод

1. Проверка ключей, неотрицательности, календаря и полной панели.
2. Пять опубликованных категорий плюс остаток «Прочие расходы», нормированные на «Все категории». Общую категорию повторно в признаки не включаем.
3. Причинно доступное среднее месячных долей за шесть месяцев. Первые пять месяцев — разогрев с расширяющимся окном.
4. Корни долей, расстояние Хеллингера и локально взвешенная union-kNN сеть при `k=12`.
5. Leiden RBConfiguration. Разрешение из `[0.5,0.8,1.0,1.3]` выбрано по среднему SW июня–августа 2023 при минимальной группе20. Финальный γ=0.5.
6. K-means и Ward при том же K и тех же признаках каждый месяц.
7. SW, CH, S_Dbw, AVI, AVU, MQ. Q и CH/N отдельно. Формулы и варианты раскрыты в отчёте и `src/metrics.py`.
8. Jaccard и венгерское сопоставление, все потоки между группами, ARI, годовые сравнения, сырые расстояния Хеллингера.
9. Чувствительность Hellinger/cosine, k=8/12/20 и окон1/3/6, повторные seed, подвыборки без возвращения, случайные разбиения с сохранением размеров.
10. Внешняя интерпретация по доступности рынков и дорожным расстояниям. Эти данные не участвуют в кластеризации.

Сглаживание не использует будущие месяцы, но полная панель выбрана ретроспективно: это описательное исследование, не производственный онлайн-мониторинг. Названия кластеров описательные, уникальные номера групп технические и не последовательны из-за рождения/слияния групп.

## Проверка

Тесты проверяют известные значения AVI/AVU/MQ/Q на полном графе и двух несвязанных треугольниках, инвариантность к номерам кластеров, рождение групп при сопоставлении, отсутствие петель при одинаковых признаках, реальную полную панель. Отдельная проверка воспроизводимости повторяет весь расчёт и сравнивает содержательные CSV без времени исполнения.
